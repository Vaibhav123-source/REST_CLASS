# Quora REST API - CRUD Operations

A RESTful API project built using **Node.js, Express.js, EJS and JavaScript** that demonstrates CRUD (Create, Read, Update, Delete) operations through a Quora-style posts application.

## 🚀 Features

- Create a new post
- Read/View all posts
- View a single post
- Edit/Update an existing post
- Delete a post
- RESTful routing
- Dynamic pages using EJS
- Simple and responsive UI

## 🛠️ Tech Stack

- Node.js
- Express.js
- EJS
- JavaScript
- HTML
- CSS
- REST API
- CRUD Operations
